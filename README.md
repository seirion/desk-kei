# Desk Kei

한국투자증권(KIS) Open API 로 국내 주식을 조회하고 주문하는 macOS 데스크톱 앱입니다. SwiftUI 로 만들었고 별도의 서버 없이 증권사 API 에 직접 연결합니다.

## 기능

- **총자산** — 총평가금액·순자산·예수금(D+2)·매입금액·총평가손익·일간평가손익 요약, 보유 종목별 현재가·평균단가·평가금액·손익(총수익/일간수익 전환)
- **관심종목** — 10개 그룹(이름 변경 가능), 종목별 1일 선차트(08:00~20:00, 분봉), 실시간 현재가·등락, 정규장 외 시간에는 NXT 시세를 `N` 배지로 함께 표시, 거래정지(정)·관리종목(관) 배지
- **주식주문** — 종목 검색(최근 종목 20개 기억), 10단계 실시간 호가창, 현재가·시/고/저/종/거래량, 지정가·시장가 매수/매도, 호가 단위에 맞춘 단가 증감, 매수가능수량 조회와 10/25/50/100% 수량 입력, 매도 시 보유 종목 빠른 선택, 주문 전 확인
- **차트** — 주문 화면의 `차트` 탭. 1/3/5/10/15/30/60분봉과 일/주/월봉 캔들, 거래량·이동평균·볼린저밴드·MACD·RSI·KDJ 지표, 확대·축소·이동, 추세선 등 그리기 도구, 상단에 종목명·실시간 가격·시/고/저/종/량 표시
- **주문내역** — 당일 전체/체결/미체결 내역, 미체결 주문 정정
- **체결 알림** — 주문이 체결되면 화면 우측 하단에 알림을 띄우고 총자산을 새로 고침
- **다중 계정** — 여러 KIS 계정을 등록하고 클릭 한 번으로 전환

## 요구 사항

- macOS 13 이상
- Swift 5.9 이상 (Xcode 또는 Command Line Tools — 단, `swift test` 는 Xcode 가 필요)
- 한국투자증권 계좌와 [KIS Developers](https://apiportal.koreainvestment.com) 에서 발급한 App Key / App Secret

## 실행

```bash
# 개발 실행
swift run DeskKei

# 앱 번들(build/DeskKei.app) 생성
Scripts/build-app.sh
open build/DeskKei.app
```

번들은 ad-hoc 서명이므로 다른 Mac 으로 옮기면 Gatekeeper 가 막을 수 있습니다. 그때는 앱을 우클릭 → 열기 로 실행하세요.

## 사용 방법

### 1. 계정 등록

처음 실행하면 계정 관리 창이 열립니다. (나중에는 `⌘,` 또는 우측 상단 사람 아이콘)

| 항목 | 설명 |
|---|---|
| 계정 이름 * | 목록에 보일 이름 |
| 계좌번호 | `00000000-01` 형식. 잔고 조회와 주문에 필요 |
| 사용자 ID | KIS HTS ID. 체결 알림에 필요 |
| App Key / App Secret * | KIS Developers 에서 발급 |

목록에서 계정을 클릭하면 그 계정으로 전환되고, 연필 아이콘으로 수정, 휴지통 아이콘으로 삭제합니다.

### 2. 관심종목

- 상단 그룹 탭으로 그룹을 전환하고, 탭을 우클릭하면 이름을 바꿀 수 있습니다.
- `⌘F` 로 종목 검색 창을 열어 종목명 또는 코드로 찾고 ★ 를 눌러 **현재 그룹**에 추가/제거합니다.
- 목록 헤더 오른쪽의 `편집` 을 누르면 편집 창이 열리고, 종목을 끌어서 순서를 바꿀 수 있습니다. 순서는 바로 저장됩니다.
- 종목 행을 우클릭하면 주문 화면으로 이동하거나 그룹에서 제거할 수 있고, 행의 `주문` 버튼은 해당 종목으로 주문 화면을 엽니다.
- 종목 왼쪽의 선차트는 오늘 1분봉이며 가로축은 08:00~20:00 고정, 점선은 전일 종가입니다. 처음 한 번 받은 뒤 실시간 체결로 이어 그립니다.
- 시세는 처음에 한 번 조회한 뒤 실시간으로 갱신됩니다. 우측 상단의 `● 실시간` 표시가 연결 상태입니다.

### 3. 주문

1. 종목을 검색해 선택하거나 총자산·관심종목의 `주문` 버튼으로 진입합니다.
2. 매수/매도와 주문 유형(지정가/시장가)을 고릅니다.
3. 호가창의 가격을 클릭하면 단가로 입력되고, `−`/`+` 로 호가 단위만큼 조정합니다.
4. 수량을 입력하거나 `10%`~`100%` 버튼으로 채웁니다. 매수는 매수가능수량, 매도는 보유수량 기준입니다.
5. 하단의 주문 버튼을 누르면 확인 창이 뜨고, 확인하면 주문이 전송됩니다.

> ⚠️ 실제 계좌로 주문이 나갑니다. 확인 창의 종목·수량·금액을 꼭 확인하세요.

**주문내역** 탭에서 당일 주문을 전체/체결/미체결로 나눠 볼 수 있고, 미체결 주문의 `정정` 을 누르면 주문 화면이 정정 모드로 열려 단가와 수량을 고쳐 다시 보낼 수 있습니다.

### 단축키

| 키 | 동작 |
|---|---|
| `⌘1` `⌘2` `⌘3` | 총자산 / 관심종목 / 주식주문 |
| `⌘F` | 종목 검색 |
| `⌘,` | 계정 관리 |

### 설정

상단 메뉴 `설정` → `설정…` 에서 앱 버전을 확인하고, `종목 마스터` 의 `지금 갱신` 으로 종목 마스터를 즉시 다시 내려받을 수 있습니다. 평소에는 앱을 시작할 때 갱신 시각을 따져 자동으로 받습니다.

### 차트

주문 화면 상단의 `주문 | 주문내역 | 차트` 에서 `차트` 를 고르면 선택한 종목의 캔들 차트가 열립니다.

- 상단에 종목명, 실시간 가격, 마우스가 가리키는 봉(없으면 최근 봉)의 시/고/저/종/거래량이 보입니다.
- `주기` 로 분봉(1·3·5·10·15·30·60)과 일·주·월봉을 바꿉니다. 분봉은 KRX 1분봉(정규장·애프터마켓)을 합쳐 만들며, 왼쪽으로 스크롤하면 더 오래된 봉을 이어서 받습니다.
- `지표` 메뉴로 이동평균(5·20·60·120)·볼린저밴드(캔들 위)와 거래량·MACD·RSI·KDJ(아래 패널)를 켜고 끕니다.
- `그리기` 메뉴에서 도구를 고른 뒤 차트를 클릭해 선을 그립니다. 그린 선은 우클릭으로 지우고, 종목을 바꾸면 모두 사라집니다.
- 차트는 [KLineChart](https://github.com/klinecharts/KLineChart) 10.1.0 (Apache-2.0) 을 `Resources/klinecharts.min.js` 로 번들해 WKWebView 에서 그립니다. 라이선스는 `Resources/klinecharts-LICENSE.txt` 에 있습니다.

### 시세 표기와 장 시간

- 상승은 빨강, 하락은 파랑입니다.
- 정규장은 09:00~15:30, NXT 는 08:00~09:00 과 15:30~20:00 (한국 시간) 입니다. 실시간 구독은 시간대에 맞춰 자동으로 바뀝니다.
- 종목 정보(종목명·기준가·거래정지/관리종목 여부)는 KIS 종목 마스터 파일을 내려받아 캐시하며, 마스터 갱신 시각이 지나면 다시 받습니다.

### 저장되는 정보

모두 `~/Library/Application Support/DeskKei/` 아래 JSON 파일로 저장되며 외부로 보내지 않습니다. 계정 정보와 토큰 파일은 소유자만 읽을 수 있게(`0600`) 만들어집니다.

| 파일 | 내용 |
|---|---|
| `accounts.json` | 등록한 계정, 사용 중인 계정 |
| `tokens.json` | 계정별 접근 토큰 캐시 |
| `watchlist.json` | 관심종목 그룹과 그룹 이름 |
| `order.json` | 마지막/최근 주문 종목 |
| `state.json` | 마지막으로 연 화면과 그룹 |
| `master.json` | 종목 마스터 캐시 |
